# Demo Media

The bar and launcher render from the QML in this checkout. Mail, tasks, calendar entries, files, clipboard items, music, device names and system readings use fictional demo data. Window entries come from four windows with generic titles in a separate Hyprland session. No real account content or clipboard history was used.

All recordings include the complete 1920-pixel-wide bar. The WebM versions retain the captured resolution at 60 fps, without audio. The looping GIF previews are 1440 pixels wide at 25 fps. The workspace GIF and WebM share a fixed bar-only crop (1440 by 30 and 1920 by 40 pixels). The pill GIF leaves less wallpaper below the bar than its video version.
